# Pong Pop!
Jogo simples onde você joga _ping pong_, mas com _pop ups_.

<img src="./demo/demo.gif" width="80%">

## Como jogar?
Acesse [https://havaianasdestruido.github.io/pong-pop/](https://havaianasdestruido.github.io/pong-pop/) ou baixe/clone esse repositório.

## Quais são os controles?
W / Seta p/ cima - Subir

S / Seta p/ baixo - Descer

## Tem suporte pra celular?
Não, você até pode ver os pop ups sendo criados no chrome pra celular, mas não tem nenhum jeito que fazer ele funcionar como no desktop pelo celular.
